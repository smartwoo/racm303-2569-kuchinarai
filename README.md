## ✨ ลำดับสไลด์และฟีเจอร์สำคัญ

1. **Instructions + QR Code สดหน้าห้อง** — สแกนแล้วแตะเลือกรูปตัวเองจาก 22 สมาชิกครอบครัวกุฉินารายณ์ได้ทันทีในคลิกเดียว
2. **การ์ดรูปถ่ายครบ 22 คน + โหมดสุ่มแนะนำตัว (`🎲 สุ่มคนถัดไป` / คีย์ลัด `R`)** — สปอตไลต์สุ่มผู้โชคดีขึ้นการ์ดใหญ่ `16:9` โดยไม่ซ้ำคนเดิม
3. **Live Word Cloud รายบุคคล (`พี่สมาร์ท`, `พี่ฟลุ๊ค`, และ นศพ. ทั้ง `20` คน)** — คำซ้ำและอิโมจิขยายขนาดอัตโนมัติแบบเรียลไทม์ ดูตารางความถี่คำ (`Results`) และซ่อนรอเฉลยพร้อมกันได้
4. **Self-Reflection Rating Scale (`1 Strongly disagree` – `5 Strongly agree`)** — ให้เจ้าของชื่อและเพื่อนๆ ให้คะแนนความตรงกับตัวตนจริง พร้อมสลับโหมด `WC + Rating 1–5` หรือ `เฉพาะ Word Cloud` ได้ตลอดเวลา
5. **Kuchi Gang 2569 Memory Yearbook** — รวบรวมคำสะท้อนและคะแนนของทุกคนสำหรับสั่งพิมพ์หรือบันทึกเก็บเป็น `PDF` / `JSON`
